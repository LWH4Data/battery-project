1. **배치 간 수명 분포가 다르다.** 현재 원본의 Batch 2는 단수명 비율이 71.8%이고 Batch 1에는 &lt;500사이클 셀이 없다. 학습 범위와 평가 범위의 차이가 핵심 과제다.

그림 5. 셀별 log10(ΔQ 분산)과 정확 순열검정의 평균 차이 분포. 1,000개 전압 좌표는 한 셀의 신호 계산에만 쓰며 독립 표본 수로 세지 않는다.

![그림 5. 셀별 log10(ΔQ 분산)과 정확 순열검정의 평균 차이 분포. 1,000개 전압 좌표는 한 셀의 신호 계산에만 쓰며 독립 표본 수로 세지 않는다.](/Users/lwh/Desktop/battery-project/outputs/day1/figures/q3_test_result.png)

**주 가설:** H0: 장수명·단수명 그룹의 모집단 log10(ΔQ 분산) 평균이 같다. H1: 두 평균이 다르다. 분산은 Ah² 수치로 ddof=0을 적용한 뒤 log10 변환했다. 다른 ΔQ 통계의 유의성 검정은 수행하지 않았다.

| 항목 | 실제 실행 결과 |
| --- | --- |
| 그룹 평균 (장 / 단) | -4.3173 / -3.3858 |
| 평균 차이 (장 - 단) | -0.9315 |
| 95% 신뢰구간 | [-1.1712, -0.6918] |
| Welch t-test | t=-12.8145, df=2.8235, p=0.001378 |
| 보완 정확 순열검정 | 4,495개 분할, 양측 p=0.0004449 |

**해석:** 두 검정 모두 5% 기준에서 H0를 기각했다. 장수명 그룹의 분산 기하평균은 단수명 그룹의 약 0.117배다. 이는 산술평균 분산의 비율이 아니다. ΔQ 변화의 퍼짐이 작을수록 긴 수명과 연관된다는 탐색 근거다.

**조건과 한계:** Welch는 평균 동일을, 순열검정은 그룹 표시의 교환 가능성 아래 동일 분포를 가정한다.[3,3b] 순열 양측 p는 작은 쪽 단측 확률의 2배다. 장수명 n=3으로 정규성을 충분히 검증할 수 없으며 셀 독립성·프로토콜 교란도 남아 있다. EDA 이후 선택한 비교이므로 독립 확증이나 인과 효과로 해석하지 않는다.

**설계 시사점:** 분산의 후보 타당성이 강화됐지만, 실제 일반화 성능과 최종 피처 채택은 Batch 1 검증으로 별도 판단한다.

| 단순 선형회귀 / 기준 모델 | ΔQ log분산의 강한 연관성을 적은 피처의 선형식으로 확인. 수명 범위 밖의 예측도 표현 가능. | 핵심 신호만 쓰는 입력과 확장 입력 비교. 정확히 중복된 피처 조합은 피하고 선형 관계의 타당성 검토. |

공선성에는 규제, 단위 차이에는 표준화

규제는 회귀 계수가 너무 커지는 것을 제한하는 방법이다. 표준화는 피처의 단위·크기를 맞춰 규제 벌점을 비교 가능하게 한다. 둘의 역할은 다르며 최종 피처와 규제 강도는 개발 검증으로 정한다.[5,5b]

분포 차이와 외삽의 한계

기본 Tree/RF는 평균·중앙값 예측 때문에 학습 수명 범위를 벗어나지 못한다.[4,4b] [534, 1,227]로 예측을 제한하면 Batch 2의 이론적 최저 MAPE도 **14.28%**다. 이는 실제 모델 성능이 아닌 clip(y,534,1227)의 수학적 하한이며, 트리 중심 전략을 재검토한 근거다.

선형·규제 회귀는 범위 밖 수명도 출력할 수 있지만 정확한 외삽을 보장하지 않는다. 배치 간 입력 범위와 피처-수명 관계가 달라지면 오차가 커질 수 있다. 과제의 Batch 1 학습 조건에서 대표성 부족은 남는 한계다.

VALIDATION DESIGN

배치 역할을 유지하는 검증 설계

---

| 단계 | 계획과 근거 |
| --- | --- |
| Batch 1 개발 | 셀 단위 Hold-out을 먼저 확보한다. 프로토콜 일반화 평가를 위해 CV와 Hold-out 모두 정책 그룹 분리를 검토한다. 비율·fold 수·seed는 착수 전 확정. |
| Train (Batch 1 CV) | 개발 부분에서 전처리·피처 선택·후보·튜닝을 수행한다. CV validation 오차의 평균과 변동을 보고하고 훈련셋에 대한 적합 오차와 구분. |
| Valid (Batch 1 Hold-out) | 후보·튜닝 선택에 계속 재사용하지 않은 Hold-out으로 과적합과 선택 결과를 점검. Hold-out이라는 이름만으로 프로토콜 분리가 보장되지 않음. |
| Test (Batch 2) | 선택·설정을 고정한 뒤 유효한 타깃의 분포를 유지해 평가. EDA에서 이미 확인한 배치임을 명시하고 결과로 재튜닝하지 않음. |
| Batch 3 선택 평가 | 같은 모델·설정으로 추가 평가. 수명 범위·원점·프로토콜 차이로 인한 일반화 변화 해석. |

처리 순서

원본·타깃 정의 점검 → 셀/프로토콜 분할 → fold train 안에서 결측 처리·피처 선택·표준화 fit → 회귀 비교 → 설정 고정 → Hold-out 및 Batch 2 평가.[6,6b] 검증·테스트에는 학습 기준으로 transform만 적용한다.

스케일링은 배치 분포 차이를 해소하지 않는다

StandardScaler는 학습 피처의 평균·표준편차로 단위를 맞춘다.[5b] 수명 분포나 피처-수명 관계의 차이를 없애거나 단수명 학습 표본을 추가하지 않는다. 배치별로 따로 fit해 분포를 강제로 맞추지 않고, 공통 기준으로 범위 안·밖의 오차를 해석한다.

Optuna 및 버전 기록

Optuna는 후보 도구다. 규제 강도와 Elastic Net 비율을 Batch 1 개발 CV의 MAPE로 비교하고 Test를 trial 평가에 쓰지 않는다. 사용 여부·범위·trial 수·seed는 착수 전 확정하고 환경·분할·코드 해시를 기록한다.

보고할 지표의 정의

MAPE(%) = 100 × 평균(|예측 수명 - 실제 수명| / 실제 수명). Gap(Train-Valid)=Valid-CV, Gap(Valid-Test)=Test-Valid, Gap(Target-Test)=Test-9.1로 계산하면 양수는 오차 증가를 뜻한다. 단위는 퍼센트포인트다. 추가 평가의 Gap(Batch2-Batch3)=MAPE3-MAPE2로 정의한다.

논문 목표와 비교할 때의 전제

과제 Target 9.1%는 비교 기준이다. 공식 코드는 처리된 Batch 1·2의 셀을 함께 학습/1차 테스트로 나누고 Batch 3를 2차 테스트로 둔다.[2] 논문 Table 1의 Full 오차는 1차 14.1%(이상 셀 제외 7.5%), 2차 10.7%다.[1] 공식 Batch 2 파일(2017-06-30)과 현재 파일(2018-02-20)도 다르므로 파일·수명 정의를 확인해야 하며 동일 성능을 보장하지 않는다.[2b]
